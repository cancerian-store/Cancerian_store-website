# Cancerian Store — Free Catalog Website

This is a static website for Cancerian Store. Customers browse the catalog and contact the store through Instagram DM.

## Files
- `index.html` — website
- `style.css` — design
- `script.js` — filters, mobile menu and product popups
- `logo.jpeg` — your supplied logo

## Before publishing
1. Replace the six sample products in `index.html` with your real products.
2. Replace the sample product visuals with your own product photos if desired.
3. Confirm the Instagram handle in `index.html` and `script.js`.
4. Update prices, sizes and descriptions.

## Publish free with GitHub Pages
1. Create a free GitHub account at https://github.com/
2. Create a new public repository, for example `cancerian-store`.
3. Upload all four website files/folders from this package.
4. In the repository go to Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide a free address similar to:
   `https://YOUR-USERNAME.github.io/cancerian-store/`

You can later connect a custom `.com` domain if you decide to buy one.
